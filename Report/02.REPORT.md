## 3. `.cursorrules` 초안

루트에 **43줄** 초안 추가. AI·TDD·ECB 공통 규칙 SSOT.

### 3.1 도메인 (규칙 고정)

| 규칙 | 내용 |
|------|------|
| 격자 | 4×4 부분 마방진, 빈칸 `0` **정확히 2개**, 완성 시 `1..16` |
| 10선 | 행4+열4+주·부대각선, 합 **34** |
| 출력 | `int[6]` → `[r1,c1,n1,r2,c2,n2]`, 좌표 **1-index** |
| 상수 | **MagicConstant SSOT** — `34`/`16`/`4` 리터럴 산재 금지 |
| 오류 | **E001~E007** (Boundary). Entity는 **E001~E005 처리 금지** (E006·E007만) |

### 3.2 아키텍처·TDD

- **ECB:** Boundary → Control → Entity. Entity → Boundary/Control import 금지.
- **TDD:** RED → GREEN → REFACTOR. assert 완화·skip·xfail·테스트 삭제로 GREEN **금지**.
- **AI:** 한국어, TDD 시 Phase/Layer/Track 선언. **git commit/push는 사용자 요청 시만**.
