## 1. 개요

### 1.1 한 줄 요약

4×4 마방진(빈칸 2, 합 34)을 푸는 학습자가 **10선 검증 누락 없이** 완료 여부를 판정하고, 틀린 축을 알 수 있게 하는 **검증·피드백** 기능을 제공한다.

### 1.2 Mom Test 기반 배경

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 격자, 빈칸 2개(0), 1~16, 합 34를 맞추는 학습자 |
| **진짜 문제** | 빈칸·합 맞추다 **행·열·대각선 전부 검증하지 못해** 잘못 완료 후 **20분** 손실 |
| **증거** | 빈칸 2·합 시도 / 대각선 1축 누락 / 20분 낭비 |

### 1.3 비목표 (Out of Scope — 1차)

- 자동 **Solver** (빈칸 채우기 알고리즘 전체)
- **PyQt** 등 풀 UI (1차는 검증 API·CLI/테스트 우선)
- TDD·도구명을 **요구사항 문장**에 넣지 않음 (개발 방식은 별도)

## 3. R-G-I-O

| | 요구 |
|---|------|
| **Role** | 학습자 — 격자를 채우고 스스로 또는 도구로 검증 |
| **Goal** | **10선** 모두 합 34일 때만 pass; 아니면 **어느 축이 깨졌는지** 확인 |
| **Input** | `int[4][4]` — 값 `0`(빈칸) 또는 `1..16` |
| **Output** | `ValidationResult { ok: bool, failures: Axis[] }` |

## 4. 도메인 규칙 (Rule)

### 4.1 격자

- 크기: **4×4** 고정
- 빈칸: `0` (과제: **2개** — 검증 전제는 PRD 1차에서 “임의 개수 허용, 완성 검증 시 0 없음”으로 구분 가능)

### 4.2 완성 격자 (strict pass)

| 규칙 | 설명 |
|------|------|
| R1 | 모든 셀 ∈ {1..16}, **0 없음** |
| R2 | 1~16 **각각 1회** (중복 없음) |
| R3 | 각 **행** 합 = 34 (4개) |
| R4 | 각 **열** 합 = 34 (4개) |
| R5 | **주대각선** 합 = 34 |
| R6 | **부대각선** 합 = 34 |

**10선:** R3 + R4 + R5 + R6.

### 4.3 부분 검증 (draft / in-progress)

- `0` 포함 격자: 완성 pass 불가; 선택적으로 **현재 채워진 축만** 합 34 여부 리포트 (2차).

## 5. 기능 요구사항

### 5.1 FR-1: `SquareValidator.validate(grid)`

| ID | 요구 |
|----|------|
| FR-1.1 | 4×4 격자 입력 |
| FR-1.2 | 10선 각각 합 계산 |
| FR-1.3 | R1~R6 위반 시 `ok=false` |
| FR-1.4 | `ok=false` 시 **위반 축 목록** 반환 (행/열/대각선 식별자) |

### 5.2 FR-2: 실패 축 리포트 (`report_failures`)

| ID | 요구 |
|----|------|
| FR-2.1 | 사람이 읽을 수 있는 축 이름 (예: `row 2`, `diag anti`) |
| FR-2.2 | 복수 축 동시 실패 시 **전부** 나열 |

### 5.3 FR-3: Command (선택 1차)

| ID | 요구 |
|----|------|
| FR-3.1 | `validate_axis(grid, axis_id)` — 단일 축 재검 |

### 5.4 FR-4: Test Loop (개발·사용 루프)

```
grid → validate → pass → 완료 인정
              → fail → failures 확인 → grid 수정 → validate
```

## 6. 수용 기준 (Mom Test 연결)

| ID | 수용 기준 | Mom Test |
|----|-----------|----------|
| AC-1 | 슬라이드 예시 **정답 완성** 격자 → `ok=true` (10선=34) | 증거 1 (맞춤 시도) |
| AC-2 | 행·열만 34, **대각선 1개** ≠ 34 → `ok=false`, 대각선 in failures | 증거 2 |
| AC-3 | `ok=false` 응답에 **최소 1개** 실패 축 명시 | 증거 3 (20분 방지·재현) |
| AC-4 | 1~16 중복 또는 0 잔존 완성 격자 → `ok=false` | F3 |
