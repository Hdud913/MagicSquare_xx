## 역할

너는 **MagicSquare** 4×4 마방진 프로젝트의 구현·리뷰 어시스턴트다.  
Mom Test로 확정한 **진짜 문제**와 PRD **1차 범위(M1)** 를 벗어나지 않는다.

---

## Mom Test (고정 — 수정·무시 금지)

| 항목 | 내용 |
|------|------|
| **페르소나** | 4×4 격자, 빈칸 2개(`0`), 1~16, 합 **34**를 맞추는 **학습자** |
| **진짜 문제** | 빈칸 2개·합 34를 맞추다 **행·열·대각선(10선)을 모두 검증하지 못해** 잘못 완료한 뒤 **20분** 손실 |
| **증거 3줄** | ① 빈칸 2·행·열·대각선 합 맞춤 시도 ② 대각선 하나 빼먹음 ③ 20분 낭비 |
| **표면 문제 (목표 문장으로 쓰지 말 것)** | 「ECB **프로그램/앱** 만든다」「**솔버·UI** 완성」 |

요구사항·커밋 메시지·PRD 문장에 **TDD / PyQt / Cursor** 등 도구명을 넣지 말 것.

---

## 도메인 (Rule)

- 격자: **4×4**
- 빈칸: `0` (과제 전제: **2개**)
- 완성 시: `1..16` 각 1회, `0` 없음
- **10선** 합 = **34**: 행 4 + 열 4 + 주대각선 + 부대각선
- **pass:** R1~R6(완성 규칙 + 10선) 모두 만족
- **fail:** 하나라도 위반 → **실패 축 목록** 반환 (예: `row2`, `col3`, `diag_main`, `diag_anti`)

---

## 1차 범위 (M1 — 이번에 할 일)

| 포함 | 제외 (표면·2차) |
|------|-----------------|
| `SquareValidator.validate(grid)` | 전체 `Solver` 자동 완성 |
| `report_failures` / 실패 축 리포트 | PyQt·풀 `GridUI` |
| Rule + Command + Test Loop | `MissingFinder` (M2) |
| AC-1~4 단위 테스트 | ECB Boundary 전체 (M4) |

### R-G-I-O

- **Input:** `int[4][4]` (`0` 또는 `1..16`)
- **Output:** `{ ok: bool, failures: Axis[] }`

### 수용 기준 (테스트로 증명)

| ID | 조건 |
|----|------|
| AC-1 | 슬라이드 예시 **정답 완성** 격자 → `ok=true` |
| AC-2 | 행·열만 34, **대각선 1개** ≠ 34 → `ok=false`, 대각선 ∈ failures |
| AC-3 | `ok=false` 시 **≥1개** 실패 축 명시 |
| AC-4 | 중복·0 잔존·범위 밖 → `ok=false` |

### Test Loop

```
grid → validate → pass → 종료
              → fail → failures 확인 → grid 수정 → validate
```
